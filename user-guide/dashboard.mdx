## Moved to Insights

Organization analytics formerly on **Dashboard** now live under **[Insights](/user-guide/insights)**.

Insights includes:

- **Conversations** — chat volume and estimated LLM cost
- **Agents** — agent performance rollup and per-agent detail
- **Workflows** — run health, duration, and failures
- **Actions** — API call volume and status codes

Open **[Insights](/user-guide/insights)** from the main navigation (admin).
